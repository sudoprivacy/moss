# Mac Studio 模型四语切换测试（给现场）

**目的：** 在同一段聊天历史里按 **中文 → 德语 → 日语 → 中文 → 英语** 提问，逐轮确认模型认出的语言、回复文字和实际声音。本测试只调用本机 ASR 代理（8002）、文本模型（8000）、语音合成（8004），不经过 Cabin、不操作座椅或灯，也不需要 Pad/token。通过只能证明模型链路可用，不能代替 Cabin 硬件回执的验收。

## 1. 在运行模型的 Mac 上执行

解压后打开该文件夹的终端（应能看到 `run.py`）。需要 `python3`、`curl`，不用安装 Python 包，不需要重启服务。

```bash
python3 run.py --make-samples
python3 run.py
```

第一条用 Mac 自带语音生成 `samples/zh.wav`、`de.wav`、`ja.wav`、`en.wav`，不覆盖已有文件。如果对应系统音色不可用，或要做正式验收，请用会说该语言的人按下表录音：每种一段、单人说话、保存成同名 PCM WAV（建议 16 kHz 单声道）。不要录乘客或使用个人信息。已有四段录音时跳过第一条。中文文件会使用两次，用于验证能否从日语切回中文。

| 文件 | 请朗读（同一个问题） | 同语种答复示例（不要求逐字一致） |
|---|---|---|
| `zh.wav` | 新鲜的青草通常是什么颜色？ | 新鲜的青草通常是绿色的。 |
| `de.wav` | Welche Farbe hat frisches Gras normalerweise? | Frisches Gras ist normalerweise grün. |
| `ja.wav` | 草は普通何色ですか。 | 草は普通、緑色です。 |
| `en.wav` | What color is fresh grass usually? | Fresh grass is usually green. |

模型目录默认 `$HOME/models-docker-mac/models`，即现场部署文档的位置。若路径不同，先执行 `export MODEL_HOME='/实际的模型目录'`。首次加载可能较慢，一次只跑一份脚本；每次会生成独立的 `results-...` 文件夹。模拟音频只用于快速验证；正式结论请用真人录音复测。

## 2. 实际测什么

1. **识别**：向 `8002/v1/audio/transcriptions` 上传 WAV，**不传 `language`**，请求 `response_format=verbose_json`。保存上游原始 `language` 及 `segments[].language`（可能是数组或仅在分段出现）。只返回文本、无语种标签时，转写可以正确，但“自动识别语种”这项记**未验证**；明确标签错误或冲突记**不通过**。
2. **对话**：把**实际转写文字**提交到 `8000/v1/chat/completions`，带上之前真实问答，不把文件名、标准答案或预期语种告诉模型。通用提示只要求按本轮问题的语言简答。判断日语轮是否仍答德语，或切回中文时是否仍答日语；不能只看答案里有没有表示“绿色”的单词。
3. **合成**：把**刚才模型的实际回复**提交到 `8004/v1/audio/speech`。默认用部署文档中的测试音色 `Vivian`，不传强制语言字段。这一轮验证“给定正确文字，当前配置实际会念成什么语言”。每段输出分别保存为 WAV。**必须试听**，HTTP 200、音频非空不算通过。若聊天文字已错，后续声音不能单独归因为 TTS。不要把 macOS 生成的输入录音误当模型输出。

例如只想先查德语识别，可在同一目录直接运行（不会发起后两步）：

```bash
curl -sS http://127.0.0.1:8002/v1/audio/transcriptions \
  -F "file=@samples/de.wav;type=audio/wav" \
  -F "model=${MODEL_HOME:-$HOME/models-docker-mac/models}/Qwen3-ASR-1.7B-8bit" \
  -F 'response_format=verbose_json'
```

期望听写出德语问题，并在顶层或分段看到 `German` / `de` 等同义标签。如果 8002 无标签但转写正常，可用同一条命令只把 `8002` 改为 `8004` 直测模型，对比两份原始结果。不要在请求中补 `language=de`，否则不是在验证自动识别。

## 3. 怎么试听、回传什么

打开最新 `results-.../report.json`，先看五轮的标签、转写和回复。再用“快速查看”或 `afplay` 依次试听各轮的 `tts.wav`，例如 `afplay results-实际目录/02-de/tts.wav`。每一轮都要满足：**标签正确、转写意思正确、回答整句为本轮语言、输出音频能听懂并与回复相符**。若某轮没得到转写或回答，脚本不会偷偷使用标准文本顶替；那轮不算完整，修复后重跑五轮。

请回传 **`report.json`、德语和日语两轮的 `tts.wav`（或问题轮的整个子目录），以及下表**。区分“语言不对”和“语言正确但口音重”。不用回传凭据或服务端全量日志。

| 02 德语 | | | | | |
| 03 日语 | | | | | |
| 04 中文（切回） | | | | | |
