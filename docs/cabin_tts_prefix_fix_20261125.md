# Cabin 中文 TTS 首字修复

## 行为

使用 Qwen3-TTS 合成明确标记为中文的音频时，Moss 默认增加已验证的播报提示：

> 用清晰、平稳的普通话播报，完整读出每一个字，句首不要吞字。

按实际 TTS profile 的语言选择，未提供 profile 时使用 `ttsLanguage`。英语、日语、韩语、粤语、自动及未知语言不会默认添加普通话提示；其他 TTS 模型也不添加。显式配置的 `cabin.ttsGeneration.instruct` 保持最高优先级，仍具有原来的全局语义。

保持原文、音色、seed 和采样参数的配置优先级。音频缓存键包含最终请求及提示，提示变化后重新合成。日志增加最终合成正文与实际提示的 SHA256，方便关联生成、上传和下载文件。

## 验证依据

2026-11-25 在现有 Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit、Vivian、seed42、temperature0.9 上复现原有首字异常，生成文件与此前坏样本摘要相同。只增加上述提示后，7 条相关回执的 ASR 辅助回读均正确；用户试听阅读灯回执确认“已读对，音色可接受”。前三条提示候选重复合成摘要一致。

这些证据支持采用当前中文提示，不代表所有动态文本都已经通过人耳验收；部署后仍应试听实际设备回执、订单、问候及长句。

## 部署

构建并部署包含本修复的 Moss 镜像。当前生产配置未显式设置 instruct，中文会自动使用新默认提示，无需新增 server.json 字段。已有显式自定义提示时继续使用该提示，需要由部署者决定是否保留。

模型权重、模型服务以及开机自启动配置无需改变。本提交只涉及 TTS，不包含 ASR 热词或采集工具，也不修改服务器配置。
