# Agent 管理 1.1：受控停用与恢复

本批补齐 AM-09 的管理操作、持久化回收与内部托管验证。它不单独证明全部 L1 平台模型路径已纳管，也不替代 R4 的真实外部平台停用验收。

## 操作

Moss → 智能体管理 → 智能体台账 → 停用，填写说明。

先持久保存停用请求并关闭本地调用入口，再调用 Nexus 的 SuspendAsset。详情中的“停用执行情况”分别呈现入口、任务身份、模型凭证、托管资源与远端任务快照。服务会继续核对待完成操作；管理员也可以点击“继续核对回收”。刷新状态只读，不触发回收或发布。

只有回收已确认，才允许重新审核通过。恢复沿用“提交审核 → 审核通过”，保留现有的权限及证据检查，不自动提高等级或延长验收有效期。旧凭证始终保持撤销；新任务需要重新取得授权。

## 边界与故障行为

- Nexus 在同一资产锁下提交停用并撤销已有 issuing/active grant。迟到的签发预检不能在停用扫描之后插入新 grant；在途 IAM 创建不能激活已撤销的 grant。
- Moss 在调用 owner 前持久保存操作。本地资产／目录入口与模型调用准入使用同一关闭标记。内部托管请求还核对停用代次，防止停用前的准入在恢复后才落库执行。
- IAM、Router 和托管资源独立回收。一处不可用不会阻止其他路径回收；没有执行服务配置时，仍检查是否有持久遗留记录，不能直接报告已清理。
- Router 创建请求发出前即持久记录不确定状态。响应丢失时只恢复凭证元数据并停用，不重发创建；未发现凭证不等于已清理，迟到创建仍需核对或等待受限有效期届满。
- 活动托管任务取消后，由原执行者响应或由到期 lease 恢复为 unknown 再清理。不能证明终止的任务保留 unknown。
- 尚未派发的外部任务停止派发；已经受理的远端任务和结果未知任务保持实际状态。此适配范围不支持确认远端取消。
- 原平台长期 Key、原平台直连模型／数据库、网关外外发不在本次回收确认范围。已经受理的模型请求仍可能产生用量。
- 正常后台核对周期为 5 秒，这不是端到端撤销 SLA。网络不可用、迟到签发及 runtime 失联时继续显示待确认。短期模型凭证的上限为 300 秒；需要结合 Router 时间同步与实际部署测量传播界限。

## 实现与兼容性

Nexus 最低实现提交：`ca181bde5`（完整 SHA 以仓库提交为准），须与本批 Moss 一并部署并停止旧 issuer。旧实现不持有资产签发锁，不能提供混合版本并行写入保证。

本批没有修改共享 wire schema。Registry 与 Task 原有 owner → SudoStack → consumer 源锁继续有效；执行语义的最低运行时版本单独说明，不能把 schema pin 当作已部署版本。

新增 Moss 表 agent_asset_gates 与 agent_asset_suspensions 为本地协调记录，不代替 Registry 资产权威或 IAM。新增表初始化是附加操作，不复制、删除或切换旧任务表。PostgreSQL 并发初始化通过事务 advisory lock 串行化。此前 Nexus request-fence 表仍须按既有显式维护流程准备。

仅组织管理员可读取及重试管理回收；普通用户和跨组织请求被拒绝。前端不接受 task owner、IAM issuer 或 Router 身份覆盖字段。持久操作记录真实管理员，任务审计另外保留原用户。

## 验证

- Nexus：46 项资产／IAM／API SQLite 回归通过；25 项独立 PostgreSQL Registry／API 回归通过，IAM 为真实 SQLite store。这不是完整 PostgreSQL IAM 或 HA 验收。
- Moss 全量检查：1246 项通过、10 项跳过；类型错误维持既有 104 基线，管理前端类型检查与生产构建通过。PostgreSQL 项另行启用真实数据库执行，不用跳过代替验证。
- Moss：新增停用、并发锁、恢复、IAM／模型回收、托管代次与跨组织回归。36 项聚焦测试含独立 PostgreSQL 连接，全部通过；外部任务组 59 项通过；管理 API 客户端 4 项通过。
- 实际管理页面：停用已验收的 Dify 合成文本资产，确认 28 项身份记录、19 项模型调用记录及 1 个托管任务的受控回收。数字是此次实验记录数，不是性能指标。
- 真实故障：独立测试 gateway 取得真实 IAM、Router 凭证并持久记录后骤停；在模型网络发送前注入故障，模型派发数为 0。停用使 grant 在到期前撤销，Router 状态为 disabled；模型记录保持 unknown，清理已确认。
- 新 Work Task 被拒绝；普通成员访问回收管理被拒绝。服务重启后继续核对完成，实际页面显示“已确认受控路径回收”。之后显式重新审核，恢复原有 L2 合成纯文本范围及同一到期时间，旧 grant 仍为 revoked。
- 私有集成证据：`/tmp/agent-v11-lab-20261021/asset-suspension-evidence.json`。凭据、实验脚本及私有证据不入库。

联调发现的旧字段统计问题已修正为 canonical external_session_bindings 关联查询，并加入含待派发／在途／unknown／跨组织场景的回归。未知状态未被改写为成功。
