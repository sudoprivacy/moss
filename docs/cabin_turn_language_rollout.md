# Cabin 逐轮语言：启用与验收

适用 `codex/cabin-status-mode-tools` 上的 `/v1/voice/query` → `/v1/ai-chat/send`。升级并重启 Cabin 后，即使现有 `server.json` 没有这两项，也默认按本轮语种回复。UE 不用升级，无需新增参数、请求头或轮次 ID。

## 如何启用

1. 两项均可省略。`conversationLanguageMode` 默认 `enabled`；`conversationTtsProfiles` 默认包含 `zh/en/de/ja/ko/fr/es/pt/it/ru`，统一使用 `Vivian`，向座位 TTS 发送 `lang_code` 和英文语种全名（如 `German`）。这不会自动打开座位播音：仍需原有 `conversationSeatAudioEnabled: true`、正确的推送地址和鉴权。
2. 如需限制语种或更换音色，可在 `cabin` 内显式设置 `conversationTtsProfiles`。它会**整表替换**默认十语：例如下面仅播英、德语；`{}` 表示逐轮模式仅返回文字。合成失败时保留文字和真实动作结果，不重发硬件。请在现场试听，不把生成 WAV 视为通过。
3. 若需先观察或回滚，显式设 `conversationLanguageMode` 为 `shadow`（仅记录逐轮判定，仍按旧逻辑回复和播放）或 `legacy`（回退旧逻辑），改后重启。删除模式键是恢复 `enabled`，不是回滚。切换影响该实例全部座位，不影响独立 TTS、广播、健康报告或 `/v1/voice-chat/send`。

```json
{
  "conversationLanguageMode": "enabled",
  "conversationTtsProfiles": {
    "en": { "voice": "Vivian", "field": "lang_code", "language": "English" },
    "de": { "voice": "Vivian", "field": "lang_code", "language": "German" }
  }
}
```

## 行为与边界

- **语音识别**：一次 `verbose_json` 读取顶层或分段的真实标签，支持 30 种名称及短码。无标签、冲突、含非支持标签时识别响应为 `unknown`，不使用乘客档案伪造识别结果。
- **两步关联**：同一会话代次、航班、乘客、座位和平板中，精确匹配最近 120 秒内唯一的未消费同文记录，不要求 `source=voice`。若是无提示识别，优先使用该轮标签；否则依次参考明确文字、合法聊天提示、受提示的匹配结果、10 分钟内的明确语言、乘客偏好、中文。显式重置不继承旧语种。两条相同的输入同时存在时宁可弃用标签，不认领其中任一条。`OK`、数字、混说和文本被改写时，不承诺总能猜对。
- **十种完整对话目标语言**：`zh/en/de/ja/ko/fr/es/pt/it/ru`。精准匹配固定说法，可覆盖阅读灯、顶灯开关、桌板开关、座椅通风/加热/按摩档位、座椅位置和阅读灯亮度。不代表任意自然语言说法都能走直控；其他说法沿用现有模型路径。设备只执行原硬件接口；成功下发、失败、桌板联锁、已处于目标状态按**实际结果**回复，不通过模型翻译。舒适建议仅接受本轮上下文中服务端已记录的待确认动作。
- **其他已识别语种**：当前交付文字问答（只读、不调用工具），不执行设备或订单、不默认改播中英文。返回的语言由模型负责，服务端对能明确判错的回复使用本地同语种澄清句；这不是对任意短句的通用语种鉴定。
- **耗时**：精准指令无需额外语言检测/翻译模型。`enabled` 先发送最终文字 `delta`，再合成与推送；原有 `done` 仍在获得播放结果后发送。客户端若只读 `done`，其完整等待时间并不会因此缩短。普通模型回复需确定最终文字才展示，本次未消除上游 ASR/模型/TTS 高分位延迟。

## 复测

```sh
bun test ./src/server/cabin/__tests__
```

1. 两次请求都省略 `language`，聊天也省略 `source`。同一座位依次说中文、德语、日语、中文、英语，再扩展到十语。核对识别标签、实际 `command` 和座位参数；`delta` 拼接、`done.reply_text`、历史、TTS 输入必须一致。
2. 在假硬件环境测试「不要打开阅读灯」、状态查询、桌板未折叠、状态缺失、控制 HTTP 200 但业务码非零，以及音频推送失败。核对下发次数，而不仅是回复文字。用两个平板说相同短句，再测会话重置、`unknown` 和缺少音色。
3. 真机用乘客录音测转写，母语听者核对座位实际播放的文字、语种、数字和否定词；不以模型标签或收到 WAV 当作试听验收。记录录音提交→ASR 返回、聊天提交→首个文字 `delta`、聊天提交→`done`、座位实际起播四个时间。比较热机、冷机和并发的 P50/P95。不要发送客户录音、令牌或生产设备请求到第三方测试服务。
