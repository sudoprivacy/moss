## 证据与原因

依据已下载的 `7A-conversation.json` 与 `cabin-7A.jsonl`，并按 request_id 关联无 seat_no 的阶段日志。以下时间均为北京时间。

| 14:44:08 → 14:44:16 | “我有点冷。”→询问是否加热；“需要。”→“没有执行设备操作。” | 同一确认词遗漏，模型自由回复又被防止虚假执行回执的保护逻辑替换。 |
| 14:24:34 → 14:24:38 → 14:24:41 | 询问是否放倒→“第二。”→“需要。” | 中间出现另一轮输入，上一轮建议按现有一次性确认规则失效；不能把后续“需要”任意用于历史操作。 |
| 14:24:10 | “放平座椅。”→SSE INTERNAL_ERROR | 直接硬件路由漏掉“放平”，模型选择控制工具后又因当前轮动作/数值不满足严格校验而被拒绝。 |
| 14:41:22 | “打开遮光板。”→SSE INTERNAL_ERROR | 模型提出的控制未通过当前请求授权；日志没有保存原始工具参数，不能断言模型具体选择了哪个设备。 |
| 14:42:17、14:42:23 | “放倒到最大状态。”→SSE INTERNAL_ERROR | 当前轮省略设备，模型控制方案不满足必须明确设备和参数的授权条件。 |

这 5 次模型错误均为 `Compact dialogue: control is not authorized by the current request`，最后被转换成 SSE `INTERNAL_ERROR`。例如“需要。”对应 `req_6625084167eb4d8d`。该错误发生在模型已经返回工具方案之后、真正执行之前，并非没有调用模型，也不是等待通用 Moss session 超时。

普通对话仍调用 LLM，携带 Cabin 会话内受字节预算限制的历史。固定问候、高置信设备命令和本地舒适度建议可以绕过模型；compact 模式不创建通用 Moss session。

当天日志另有 4 次 `ASR_NO_SPEECH`（14:02:41、14:02:43、14:03:09、14:21:48），表示输入录音未识别出有效文字，与工具授权失败不同。现有日志没有这些轮次的原始录音，无法区分录音空白、采集截断或 ASR 漏识别，未声称已修复这部分。

## 本地修改

- 补充“需要/需要的/要/要的/行/嗯嗯”确认词，仍要求当前会话、座位、终端范围内存在未过期的有效建议，只能执行一次。
- 将“我有点困”“我感觉有点累”“我有点想睡觉”等完整陈述统一到可确认的本地舒适度建议；否定、条件句和疑问句不会作为确认或舒适度操作请求。
- 明确包含座椅的“放平座椅”“把座椅放倒到最大状态”路由到 `seat.cushion position=100`。“最大状态”在完整指令中不再误判为状态查询。设备未指定的“放倒到最大状态”继续追问，不补用历史设备。
- 模型工具方案因授权或参数校验被拒绝时，保留校验和拒绝日志，标记 `tool-rejected/not_executed`，返回正常的澄清回复。不会发送模型未经授权的命令，也不使用模型附带的“已完成”文案。
- 网络错误、模型 HTTP 503 等真实上游故障仍报错误，不用澄清文案掩盖。

## 后续：有效动作的语义确认

针对用户指出的词表限制，当前启用的多语言对话路径已加入独立、受限的模型语义判断。固定词表仅用于加速常见的简短确认；其他表达在存在有效动作时使用该判断，返回 confirm、decline、modify、unclear、unrelated 五类之一。请求只包含服务器保存的动作和当前输入，不包含座位身份、任意历史或可执行工具。模型不得返回或追加命令、设备、座位、参数。

- “行，帮我调一下”“可以，我想休息”等表达无需加入词表；模型判断为明确确认后，执行保存的同一动作。
- 已明确指定设备和数值的修改请求走现有直接路由；其他修改要求补充说明，撤销旧动作，避免随后一句“好”误执行原方案。
- “第二”等不明确表达重新询问原建议，并保留原有效期。它不再像此前那样直接丢失建议；后续明确确认可以执行。
- 拒绝、换话题或另一项明确请求会清除旧建议；新的舒适度请求会替换旧建议。
- 动作保存随机版本标识；模型返回后再次检查会话重置版本和有效期，原子消费动作。并发确认最多下发一次，过期、被替换、已消费或会话已重置时不能执行。
- 模型不可用、返回截断、JSON 不合规、携带额外参数或工具调用时不执行，继续询问；不会重新延长原有效期。
- 使用现有三列表保存结构化动作，无需增加数据库列或修改 server.json。旧版本读取新格式建议时不会执行它；部署切换前遗留的旧格式建议需要重新询问确认。

范围限制：这条语义确认链路只用于服务端已登记的有效动作。普通模型自由生成的任意操作建议尚未全部登记，不能声称所有模型建议均支持后续确认；“我累了”当前默认建议座椅放倒，“我腰酸”默认建议按摩。
